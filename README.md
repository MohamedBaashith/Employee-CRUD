# Employee Management System 🏢

## 📌 Overview
This is a **basic CRUD operation-based project** built using:  
- **Backend:** Go (Gin Framework)  
- **Frontend:** React.js  
- **Database:** MongoDB  

It provides functionalities to **Create, Read, Update, and Delete (CRUD)** employee details.

---

## 🚀 Features
✅ User Registration & Login  
✅ Add, Edit, Delete Employee Details  
✅ Fetch Employee List  
✅ Secure API with JWT Authentication  

---

## 🛠️ Tech Stack
- **Frontend:** React.js, Recharts (for visualization)  
- **Backend:** Golang (Gin Framework)  
- **Database:** MongoDB  
- **Authentication:** JWT

## 🛠️ Setup Instructions

```sh
