# Employee Management System 🏢

## 📌 Overview
This is a **basic CRUD operation-based project** built using:  
- **Backend:** Go (Gin Framework)  
- **Frontend:** React.js  
- **Database:** MongoDB  

It provides functionalities to **Create, Read, Update, and Delete (CRUD)** employee details.

---

## 🚀 Features
✅ User Registration & Login  
✅ Add, Edit, Delete Employee Details  
✅ Fetch Employee List  
✅ Secure API with JWT Authentication  

---

## 🛠️ Tech Stack
- **Frontend:** React.js, Recharts (for visualization)  
- **Backend:** Golang (Gin Framework)  
- **Database:** MongoDB  
- **Authentication:** JWT  

---

## 🛠️ Setup Instructions  

### 1️⃣ **Clone the Repository**  
Open your terminal and run:  
```sh
git clone https://github.com/MohamedBaashith/YourRepoName.git
cd YourRepoName
```

### 2️⃣ **Backend Setup (Golang)**
```sh
cd Myproject
go mod tidy
go run main.go
```
Backend runs on: http://localhost:5000

### 3️⃣ **Frontend Setup (React.js)**
```sh
cd myapp
npm install
npm start
```
Frontend runs on: http://localhost:3000
